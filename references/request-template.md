# ArcGIS Pro 脚本工具需求模板（新版）

> 复制下面「模板正文」填空后发给 AI（Claude Code 装了本 skill 时直接发；其他 AI 也能用）。
> 可以写成一个 `.md` 文件，然后说"按 @需求.md 写脚本工具"——不用再担心提问太长。

## 相比旧模板，这些不用再写了

| 旧模板里的内容 | 为什么删掉 |
| --- | --- |
| "你是一个专业的 ArcGIS Pro 二次开发工程师" | 领域规则已经写在 skill 里，角色扮演不增加信息 |
| "必须基于 ArcGIS Pro，Python 3.x" | skill 默认就是 Pro + Python 3；只有 ArcMap 10.x 时才需要特别说明 |
| "用 AddMessage/AddError 输出成功、失败、异常" | skill 的硬性规则 |
| "运行完释放资源、删除临时文件" | skill 的硬性规则 |
| "如果需要更多信息请向我提问" | skill 规定了：先做需求体检，再一次性用选择题提问 |
| "代码别被会话截断，可以分批给" | Claude Code 直接把 `.py` 写到磁盘，不存在截断问题 |
| "提问过长用 pastebin" | 直接引用本地文件（`@路径`）即可 |
| 粘贴一大段官方帮助示例 | 常用工具 AI 都知道；只有冷门或新版工具才需要贴签名 |

**要多写的**：验收标准、数据规模、坐标系、测试数据路径——这些是旧模板缺的，也是 AI 最容易猜错的地方。

## 模板正文

```markdown
# ArcGIS Pro 脚本工具：<工具中文名>（文件名建议：<EnglishName><中文名>.py）

## 1. 一句话目标
<例：把文件夹下（含子文件夹）所有同名 shp 合并到目标 GDB，并记录来源路径>

## 2. 处理逻辑
1. <步骤一>
2. <步骤二>
- 有歧义的规则，务必给一个"输入 → 输出"的小例子（例：前缀 510104001 + 后缀位数 4 → 5101040010001）
- 可选（强烈推荐）：在 Pro 里手动跑通一遍，到「历史」里右键 →「复制 Python 命令」，贴在这里。
  这能把工具名、参数写法、字段表达式都钉死。临时路径不用改，AI 会换成参数和临时工作空间。

## 3. 工具参数
<!-- 已在 Pro 里配好：照抄；还没配：写"帮我设计参数"，AI 会给出参数表或 .pyt -->
| 序号 | 标注 | 名称 | 数据类型 | 必填/可选 | 方向 | 多值 | 依赖 / 过滤器 / 默认值 | 说明 |
| ---- | ---- | ---- | -------- | --------- | ---- | ---- | ---------------------- | ---- |
| 0    |      |      |          |           | 输入 |      |                        |      |

## 4. 数据情况
- 格式：<GDB / shp / 栅格 / Excel(xls 还是 xlsx) / 文本>
- 结构：<有无要素数据集？独立表？要读 Excel 的哪张表、哪几列、第几行开始？>
- 坐标系：<投影坐标系 / 地理坐标系>（算面积、距离、长度时必须写）
- 规模：<约多少要素、多少个 GDB——决定写法是否要考虑性能>
- 特殊情况：<空值、中文字段名、曲线要素、多部件、字段名在不同数据里不一致……>
- 样例：<Excel 表头 + 两三行样例；关键字段的几个真实取值>

## 5. 输出与验收
- 输出：<输出什么、放在哪、怎么命名；是否加时间戳防止重名>
- 原数据：<直接修改原数据（是否需要先备份）还是输出新数据>
- 是否加到当前地图：<是/否>
- 验收标准：<例：输出 5 个要素类；每个都有 shpPath 字段且没有空值；字段并集正确>
- 测试数据：<路径（可选）。有的话 AI 写完会直接跑一遍>

## 6. 环境（不写则按默认处理）
- ArcGIS Pro 版本：<默认按本机版本>；许可：<Basic/Standard/Advanced；是否有 Spatial Analyst>
- Python 环境：<默认 arcgispro-py3-clone>
```

## 修改已有工具时

改已有工具比新写更常见，这时只需要：

```markdown
改造 @py/<已有脚本>.py：
- 现状：<它现在做什么；哪里不满意 / 报了什么错（贴 Pro 消息窗口的完整报错）>
- 目标：<改成什么，例如"单库 → 多库批处理"、"结果输出到 Excel">
- 参数变化：<新增 / 删除 / 修改了哪些参数（给出序号）>
- 不能动的：<例如参数顺序已被别的模型引用，不能改>
- 验收：<……>
```
